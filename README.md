# ana-la-mejor

Vacantes de plantilla a jornada completa de Lengua Extranjera: Inglés (PROA y Maestros de Primaria) en centros de la Región de Murcia, con mapa interactivo y ordenación por cercanía a una ubicación.

Publicado con GitHub Pages: https://antolin1.github.io/ana-la-mejor/

Datos de vacantes: convocatoria de la Región de Murcia. Coordenadas de los centros: API pública de [mapaescolar.murciaeduca.es](https://mapaescolar.murciaeduca.es).
